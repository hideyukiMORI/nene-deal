# Daily reports — NeNe Deal

Per-repo daily work log. One file per day: `docs/daily/YYYY-MM-DD.md`. Multiple
sessions in a day append under a `## Session 2` heading in the same file.

Format and conventions are governed by the fleet source-of-truth
`_work/daily-report-convention.md`. Minimum: `# YYYY-MM-DD` heading, a lead
paragraph, `## <topic>` sections listing what was touched (with PR/Issue numbers)
plus evidence and follow-ups. When a number is written, always mark whether it is
`[measured]` or `[reported]`.

Repo docs stay English (AGENTS.md), so reports here are written in English while
following the fleet format.

## What goes where

- **`docs/daily/`** — work done *inside this repo*.
- **Cross-repo / strategy / business discussion** — lives in `_work/daily/` and
  `_work/discussion-log/` (the `/home/xi/docker` workspace convention), not here.
- **Historical logs before 2026-07-17** live in `docs/journal/` (kept in place; not
  migrated, per the convention's Appendix A for deal).
