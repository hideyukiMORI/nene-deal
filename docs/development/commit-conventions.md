# Commit Conventions

Conventional Commits. Type/scope in English; description/body may be Japanese.

```
<type>(<scope>): <description> (#<issue>)
```

Include GitHub Issue number in subject when practical.

| type | Use |
| --- | --- |
| `feat` | New feature |
| `fix` | Bug fix |
| `docs` | Documentation only |
| `chore` | Maintenance |
